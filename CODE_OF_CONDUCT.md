# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, assume good intent, and remember that many people here are learning. Questions are welcome,
mistakes are normal, and nobody is "too beginner" to contribute. Harassment, insults and personal attacks are not
tolerated.

Report a problem privately to the maintainers through the contact on the
[repository owner's GitHub profile](https://github.com/daniis-h). Reports are handled confidentially.
